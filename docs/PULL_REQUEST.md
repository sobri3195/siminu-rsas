Surat masuk kini dapat dinilai perlu balasan dan ditautkan ke konsep, pemeriksaan, surat keluar, serta bukti pengiriman. Membuat atau menyetujui konsep tidak menutup kewajiban: semua tujuan pada setiap balasan harus tercatat dikirim, atau petugas menutup kebutuhan balasan dengan alasan yang masuk riwayat.

- Memperluas editor naskah/versi/template yang ada: sumber berdasarkan ID, balasan tambahan eksplisit, lampiran terpilih dan penggantian berkas dengan riwayat, format paragraf/tebal/miring/daftar/tabel bersama untuk A4 dan DOCX editable, serta penanganan konflik tab tanpa menghapus input.
- Menambahkan antrean Perlu Dibalas dan Pemeriksaan Surat, dashboard pekerjaan, rangkaian/kronologi surat, register nomor transaksional dengan pembatalan beralasan, serta ekspedisi manual multi tujuan/percobaan dan penerimaan terpisah.
- Mengunci surat terbit; revisi dan pemulihan menghasilkan versi baru. Surat keluar dan nomor historis dipertahankan. Arsip memeriksa kewajiban balasan dan pengiriman yang masih terbuka.
- Migrasi IndexedDB v6 menambah lima tabel tanpa menghapus data. ZIP v6 mencakup relasi, template, versi, nomor, lampiran asli serta bukti kirim/terima; paket v2–v5 tetap terbaca. Konflik nomor lintas pemilik ditampilkan dan memblokir merge; replace memerlukan konfirmasi dan cadangan otomatis.
- Membundel font fallback Liberation Serif/Sans berlisensi OFL ke precache lokal, mempertahankan worker PDF.js/DOCX lokal dan konfigurasi Vercel SPA, serta menyediakan contoh dan panduan uji coba.

Validasi: TypeScript dan build produksi lolos; 67 tes repository serta 25 skenario Chromium lolos. Pengujian terarah editor/lampiran diulang setelah penyelarasan urutan ekspor dan tetap lolos. Alur lengkap dijalankan offline dengan nol request HTTP eksternal; dua tab memperebutkan satu nomor hanya menghasilkan satu pemilik. DOCX dibuka LibreOffice (tiga halaman A4); PDF normal tiga halaman dan draf panjang lima halaman dengan penanda akhir utuh. Contoh DOCX/PDF, lisensi font dan panduan disertakan. Rincian: docs/VERIFICATION.md.

Format resmi RSAS dan pola nomor resmi belum diberikan; template/pola bawaan ditandai rancangan. Peran, persetujuan dan pengiriman merupakan pencatatan/simulasi lokal. Data tidak tersinkronisasi antarperangkat. Tidak ada klaim pengiriman otomatis atau tanda tangan elektronik tersertifikasi.
