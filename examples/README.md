# Contoh dokumen lokal

`nota-dinas-generik.docx` dan `notulen-generik.docx` dibuat oleh fungsi ekspor aplikasi melalui pengujian browser, berisi teks DOCX yang dapat diedit. Seluruh nama/isi adalah data uji. Berkas ini bukan format resmi RSAS dan tidak mengandung tanda tangan atau stempel.

Untuk membuat contoh sendiri: buka Pembuat Naskah, pilih Nota dinas, isi tujuan/isi, lalu Ekspor DOCX. Buka Notulen untuk menulis keputusan dan mengekspor DOCX notulen. Contoh template impor metadata dapat diunduh pada Impor Register untuk register masuk atau keluar.
